# 0013. Физические материалы на CPU и GPU

Статус: принято, 2026-11-27.

## Контекст
Материалы сцены — Ламберт, металл с размытием, стекло, пластик с покрытием, излучатель. Для разнообразия картинки нужны свойства, которые зависят от длины волны, от микрорельефа поверхности, от рассеяния под поверхностью, от узора и от времени. Каждое должно работать и в CPU-ядре (ADR 0008), и в шейдере GPU-режима (ADR 0009), а эталон golden-теста Classic — не меняться.

## Решение
Общие правила:
- Новое свойство — либо новый параметр с нейтральным значением по умолчанию (тогда старые сцены считаются отсчёт в отсчёт как раньше: ни одного лишнего случайного числа), либо новый класс материала.
- Материал остаётся неизменяемой моделью с чистым `scatter`. Формулы, которым нужен отдельный тест, лежат в объекте-неймспейсе рядом (`Spectrum`, `ThinFilm`).
- Шейдер повторяет каждую формулу построчно, со ссылкой на функцию Kotlin в комментарии. Код материала в текстуре сцены и раскладка параметров описаны в `GpuScenePacking.material`. Тест `GpuTracerTest` сравнивает кадры CPU и GPU по яркости, для цветных эффектов — по каналам.

### Дисперсия
- `Dielectric.dispersion` — коэффициент Коши: показатель преломления растёт к коротким волнам, `indexOfReflection` остаётся показателем на линии d.
- Белый луч, впервые попавший в такое стекло, выбирает одну длину волны равномерно в 380–720 нм и дальше несёт её в `Ray.wavelength`. Вес пути умножается на `Spectrum.weight` — цвет этой длины волны, нормированный так, что среднее по всем длинам волн белое. Так оценка остаётся несмещённой, а второе попадание в то же стекло (выход из призмы) преломляет ту же волну.
- `Ray.time` и `Ray.wavelength` переносятся на следующий луч через `Ray.next`, отдельного состояния пути в ядре нет. В шейдере длина волны — локальная переменная цикла.

### Тонкая плёнка
- `ThinFilm.at` — формула Эйри для одной плёнки между воздухом и подложкой, среднее двух поляризаций. Для белого луча она считается на трёх длинах волн каналов RGB, для луча с длиной волны — на ней.
- `SoapBubble` — плёнка с воздухом с двух сторон: отражает или пропускает луч насквозь без преломления. `Iridescent` — плёнка на диффузной основе (масло на асфальте, панцирь жука).
- Ветвь выбирается с вероятностью средней отражательной способности, вес делится на эту вероятность.

### Гладкие нормали, микрограни, металлы
- `Triangle.normals` (`VertexNormals`) — нормали в вершинах, смешанные по барицентрическим координатам. Сторона попадания (`isFrontFace`) берётся от плоской грани, иначе стекло путает вход и выход на силуэте. `Meshes.smooth` усредняет нормали граней по площади, острые углы оставляет плоскими; OBJ-файлы берут нормали из `vn`, если они есть.
- В текстуре GPU у примитива одиннадцатое значение — номер записи нормалей (0 — плоский треугольник), сами нормали — отдельный раздел. Пересечение их не читает, только затенение.
- `Microfacets` — распределение GGX с шириной `alphaX`/`alphaY`, выборка видимых нормалей (Heitz 2018) и затенение Смита G2/G1. Касательная идёт по кругу вокруг вертикальной оси: анизотропный металл выглядит точёным.
- `Conductor` — металл с комплексным показателем преломления (точная формула Френеля для проводника) и микрогранями; `Metals` — измеренные η и k золота, меди, хрома, серебра, алюминия. Старый `Metal` с размытием остаётся: на нём golden-тест.
- `Dielectric.roughness` — матовое стекло: отражение и преломление на микрограни, лучи, ушедшие не на ту сторону поверхности, гаснут.

## Последствия
- Дисперсия добавляет цветной шум: путь через призму несёт одну волну, радуга собирается из многих отсчётов.
- Шейдер растёт на функцию на материал. Ветви, которых нет в сцене, GPU не исполняет, но время компиляции шейдера растёт.
