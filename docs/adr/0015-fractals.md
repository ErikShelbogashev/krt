# 0015. Фракталы по оценке расстояния

Статус: принято, 2026-11-27.

## Контекст
Нужны фракталы: Mandelbulb, губка Менгера, Mandelbox, кватернионное множество Жюлиа. Сетка из треугольников даёт гранёную поверхность и сотни тысяч примитивов в текстуре GPU, процедурный узор — только плоскую картинку.

## Решение
- На GPU предел числа итераций вложенной формулы равен 8 для губки Менгера и 16 для остальных видов. При импорте PBRT сверх этого предела выводится предупреждение с обоими значениями. CPU использует заданное число итераций.
- `Fractal` — примитив сцены: вид (`FractalKind`), центр, радиус ограничивающего шара, материал, число итераций, параметр (степень Mandelbulb, масштаб Mandelbox) и константа Жюлиа. Внутри шара луч идёт шагами длиной в оценку расстояния до поверхности (sphere tracing), не больше 160 шагов, поверхность — ближе десятитысячной доли радиуса. Нормаль — градиент оценки по четырём точкам тетраэдра.
- Оценки расстояния (`FractalDistance`) — чистые функции в собственных координатах фрактала; `Fractal` масштабирует их в шар заданного радиуса. Шейдер повторяет их построчно, во float.
- В BVH и в текстуре GPU фрактал — обычный примитив (вид `FRACTAL`) с ограничивающим шаром. Любой материал krt подходит.
- В файлах сцен pbrt-v4 фрактал записывается расширением `#krt`, с запасной фигурой для настоящего pbrt (ADR 0016).

## Последствия
- Попадание во фрактал в десятки раз дороже шара: оценка расстояния — 4–16 итераций на шаг, шагов — десятки. На GPU это заметно только в сцене с фракталами.
- CPU считает в double, GPU во float: силуэты совпадают до долей пикселя, тесты сравнивают кадры по яркости.
- Фракталы не светятся как источники для выборки: излучающий фрактал видно только по пути.
