# Стратификация пикселей

Режим **Stratified pixel sampling** уточняет долю пикселя, покрытую объектом. Случайный луч проходит через заданную ячейку внутри пикселя. При 4, 16, 64 и 256 отсчётах лучи покрывают соответственно сетки 2×2, 4×4, 8×8 и 16×16 по одному разу. Для каждого пикселя и кадра выбирается случайное начало последовательности. Разбиение прохода на полосы сохраняет номера отсчётов. Линза, источники света и рассеяние по-прежнему семплируются независимо. [PBRT v4, Stratified Sampler](https://pbr-book.org/4ed/Sampling_and_Reconstruction/Stratified_Sampler)

## Изображение за 600 мс

Команда `./gradlew --offline gpuSmoke -Pscene=pixel-sampling` проверяет границу и Materials с обычной текстурой. Команда `./gradlew --offline gpuSmoke -Pscene=pixel-sampling-wood` включает фильтрацию дерева в Materials. Стенд сравнивает последнюю опубликованную картинку в момент 600 мс с начала запроса. Это включает черновик и ожидание уточнения. Используются штатные CPU-потоки и отдельный Metal-контекст, кадр 128×128 и четыре повтора каждого режима. Порядок режимов чередуется. В таблице медианная среднеквадратичная ошибка по RGB в единицах 8-битного канала и в скобках диапазон четырёх замеров. Меньшее значение соответствует более точной картинке.

| Сцена и рендерер | Независимые отсчёты | Стратификация |
| --- | ---: | ---: |
| Диагональная граница, CPU | 6,18 (3,07–10,64) | 1,76 (1,56–2,69) |
| Диагональная граница, Metal | 5,86 (5,16–6,30) | 1,74 (1,64–1,80) |
| Materials, CPU | 22,12 (19,59–22,71) | 21,31 (19,34–22,10) |
| Materials, Metal | 22,39 (21,64–24,31) | 22,52 (21,02–23,75) |
| Materials с фильтрацией дерева, CPU | 19,26 (16,45–20,53) | 18,81 (16,69–20,65) |
| Materials с фильтрацией дерева, Metal | 22,29 (21,57–23,51) | 23,41 (21,24–26,38) |

На диагональной границе каждый затронутый пиксель закрыт белым излучателем ровно наполовину. Эталон яркости на границе равен 0,5 в линейном пространстве, или 180 после преобразования для экрана. Стратификация снизила медианную ошибку примерно на 70% на обоих рендерерах. На Metal оба режима закончили все 256 отсчётов до истечения бюджета.

В Materials измеряется весь кадр со стартовой камеры, глубина 6. Эталон построен отдельно для каждого рендерера и положения фильтра дерева при 512 отсчётах, с независимой выборкой и другим начальным состоянием генератора. Старая текстура служила предварительным контролем. После захвата картинки следующий запрос мог отменить хвост предыдущего. В контроле CPU завершил 10–16 проходов к дедлайну, Metal 8–12.

В замере с фильтрацией дерева после снимка программа ждала полного завершения всех 256 отсчётов до переключения режима. CPU успел показать 12–27 проходов за 600 мс, Metal 4–12. Такой порядок отделяет вычисления соседних запросов и используется в обеих командах воспроизведения. Диапазоны ошибок независимой и стратифицированной выборки перекрываются и при включённом фильтре. Для зерна от непрямого света или размытия конечной апертуры устойчивый выигрыш здесь не установлен. Поэтому обычная независимая выборка остаётся начальным режимом.

## Автоматическая проверка

`StratifiedPixelTest` проверяет покрытие всех ячеек для всех 256 начальных смещений. На аналитической диагонали при 16 отсчётах сравниваются 8 независимых последовательностей для CPU и SkSL. На пересечённых пикселях среднеквадратичная ошибка должна уменьшиться минимум на 20%, а остальные пиксели должны совпасть с белым или чёрным эталоном. Ещё одна проверка сравнивает один проход SkSL на 16 отсчётов с двумя проходами на 7 и 9. Допуск в один экранный код учитывает округление промежуточного цвета.
